# HW1 · Fully Connected Networks (PyTorch)

Manual ReLU, Linear and Softmax + cross-entropy layers with hand-written forward/backward passes (`derivatives.py`), assembled into an MLP and trained on `sklearn` digits (8×8). Experiments with depth (3/4/5 layers), weight initialization and activation functions.

Results (from notebook outputs): test accuracy mostly ~92–97% (best 96.89%); some initializations diverge.
